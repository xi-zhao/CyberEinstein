# CyberEinstein 发展愿景

- 状态：方向基线
- 日期：2026-08-26

## 1. 我们要建设什么

CyberEinstein 的长期目标是成为能够参与真实科研、持续修正自身判断并帮助人类产生重要新知识的 AI 科学家。

它不是论文问答工具、自动写作工具或单次实验 Agent。它是一套科研工作台和科学执行系统：先理解我们实际拥有的科研能力，再建立研究方向的数据与证据基础，随后通过复现、优化、发现、验证和经验回流持续推进科研。

> CyberEinstein 是产品与科研系统，DeepSeek Harness 是可替换的 Agent 运行内核。

## 2. 科技向善与做科学家的梦想

> 我们希望让每一个人，都有机会在自己感兴趣的科研方向上成为爱因斯坦，完成自己做科学家的梦想。

这里的“成为爱因斯坦”不是承诺每个人必然产生改变世界的发现，而是让每个怀有科学好奇心的人，都有机会获得提出深刻问题、理解研究脉络、设计严谨验证和把想法推进为成果的能力。

CyberEinstein 不以替代科学家为目标，而是扩大人的科研自主性。它要帮助学生、独立研究者、小型实验室和跨学科探索者跨过知识、工具与基础设施门槛，让科研能力不再只集中在少数机构和专家手中。

科技向善不能停留在口号上。产品必须遵守以下承诺：

- **能力普惠**：用可理解的解释、可执行的流程和可连接的科研设施降低进入门槛。
- **标准不降**：让更多人参与科研，不意味着降低证据、复现、统计和同行审查标准。
- **尊重人的贡献**：完整记录来源、作者、实验人员和协作者，AI 不占用人类的真实贡献。
- **安全与责任**：对安全、伦理、隐私、环境和双重用途风险进行独立评估，高风险行动保留人类决策权。
- **公共价值**：不仅判断研究能否成功，还要追问谁会受益、谁可能受损，以及成果是否增进人类福祉。
- **机会而非保证**：平台提供成为优秀研究者的能力和机会，不制造人人都能获得重大发现的虚假承诺。

这意味着每个重要研究项目都需要 `ImpactAssessment`：记录预期受益、潜在伤害、双重用途、公平可及性、知识产权、署名方式和必要的风险缓解措施。

## 3. 科研从能力边界开始

任何研究计划开始前，系统必须先回答三个问题：

1. 我们现在能够执行什么？
2. 哪些关键能力缺失？
3. 这个问题应当通过计算、物理实验还是混合方式验证？

`CapabilityGraph` 不能只是资产清单。每项能力都应记录：

- 能力类型与可执行操作；
- 输入、输出和数据格式；
- 精度、量程、吞吐量和校准状态；
- 可用容量、排队时间、成本和负责人；
- 数字接口、控制权限和自动化程度；
- 安全、伦理、合规和环境限制；
- 已知故障、历史偏差和适用边界。

算力只是其中一部分。纯计算研究还需要可信数据、可复现软件环境、经过验证的模拟器和不会诱导错误优化的评价指标。物理实验还需要样品、场地、仪器、操作规程、校准和实验人员。

## 4. 不同实验需要不同闭环

CyberEinstein 按照实际执行依赖，而不是简单按照学科划分研究任务：

| 执行类型 | 典型基础设施 | CyberEinstein 的角色 |
| --- | --- | --- |
| 理论与形式推导 | 文献、符号计算、定理与验证器 | 形成推导、检查前提、寻找反例 |
| 纯计算实验 | 算力、代码、数据、模拟器和指标 | 设计、执行并自动分析完整闭环 |
| 人工物理实验 | 样品、仪器、人员和实验规程 | 设计协议、指导执行、记录和审查 |
| 数字化仪器实验 | 可编程设备、传感器和设备接口 | 编排半自动实验和反馈控制 |
| 机器人实验室 | 自动制样、测量、调度和安全系统 | 在约束内形成自主实验闭环 |
| 混合研究 | 计算筛选与物理验证设施 | 在仿真和真实世界之间迭代校准 |

首个产品应优先选择能够形成数字闭环的计算研究，同时从一开始保留接入物理实验和数字化仪器的能力模型。

## 5. 建立研究方向的数据基础

在生成新 idea 之前，CyberEinstein 需要理解一个方向是如何发展到今天的。PRAgent（论文与研究方向 Agent）的职责不应停留在论文总结，而应建设 `FieldMap`：

- 关键科学问题和概念如何演化；
- 重要方法、理论和实验路线之间的继承关系；
- 里程碑论文、最新进展和代表性研究团队；
- 常用数据集、实验平台、基准和评价指标；
- 当前共识、开放争议和相互矛盾的结果；
- 已知失败路线、负结果和长期未解决问题。

这里不存在“收集完某方向所有数据”的终点。系统应定义研究就绪门槛，在覆盖关键历史、前沿论文、主要 Claim、锚点复现和基础评价体系后启动有限研究，并在执行中持续补全 FieldMap。

## 6. 论文复现是证据基础设施

论文不是不可分割的整体。CyberEinstein 需要把论文拆成不同类型的 Claim：

- 背景与事实 Claim；
- 方法和实现 Claim；
- 经验结果与性能 Claim；
- 因果或机制解释 Claim；
- 泛化与适用范围 Claim；
- 新颖性和研究意义 Claim。

不同 Claim 需要不同验证方式。论文复现也不是“成功或失败”的二元状态，而应区分：

1. 理解并结构化论文；
2. 建立可运行环境；
3. 重现关键图表、结果或指标；
4. 独立重实现并检查基线、噪声、参数和稳健性。

复现过程要主动收集论文正文没有充分披露的细节，例如数据清洗、排除规则、随机种子、超参数、仪器校准、样品处理、失败实验和研究者的隐性经验。这些内容与 Claim、运行记录和证据的关联，才构成真正的数据基础设施。

## 7. 从复现走向研究机会

`OpportunityMap` 从已有证据中寻找值得研究的位置：

- 无法稳定复现的结果；
- 论文之间互相冲突的 Claim；
- 对参数、数据或设备高度敏感的结论；
- 基准已经饱和但真实问题没有解决的领域；
- 现有理论无法解释的异常；
- 仿真与物理实验之间的系统偏差；
- 关键能力缺失导致长期无法验证的问题。

机会必须被转化为可证伪假设，并明确需要什么证据才能支持、反驳或区分不同解释。

## 8. 三类研究 Loop

### 8.1 工程优化 Loop

当目标、指标和搜索空间较明确时，采用类似 Auto Research 的循环：生成改进方案、执行实验、比较基线、保留有效变化并继续搜索。

系统必须使用留出测试、稳健性检查和独立基线，避免只对公开指标过拟合或通过修改评价方式制造虚假进步。

### 8.2 机制发现 Loop

从异常、矛盾和边界条件出发，同时维护多个竞争假设，优先执行最能区分这些假设的实验：

```text
异常或矛盾
-> 竞争假设
-> 信息增益最大的实验
-> 主动寻找反证
-> 更新机制理解
-> 独立复现
```

Discovery 不能主要依赖无约束穷举。大规模搜索容易产生偶然显著、指标投机和无法解释的相关性，应结合实验设计、主动学习、因果分析和反事实检查。

### 8.3 范式发现 Loop

真正重大的发现往往来自重新定义问题、变量或理论表示，而不是在旧搜索空间中找到更优参数。这是当前 AI 最难独立完成的部分。

CyberEinstein 的近期目标应是帮助人类暴露矛盾、生成跨领域类比、压缩解释并设计判别实验。能够自主形成新范式是长期研究问题，而不是早期产品承诺。

## 9. 所有 Loop 都包含 RSI 经验回流

RSI 在这里指受控的 Recursive Self-Improvement，即系统根据可验证经验持续改进判断和流程，而不是未经审查地改写自身。每个科研 Loop 都由任务循环和元学习循环共同组成：

```text
任务循环：提出假设 -> 设计 -> 执行 -> 验证

RSI 循环：检索旧经验 -> 预测风险 -> 诊断偏差
         -> 提炼经验 -> 独立验证 -> 更新规则
```

任务开始前，系统必须检索相似问题、设备、数据、方法和指标下的历史失败。任务结束后，无论成功或失败，都要比较预期与实际结果，并记录偏差。

一条 `FailureExperience` 至少包括：

- 当时的任务、环境和上下文；
- 模型原本的判断和预期结果；
- 实际结果与关键偏差；
- 根因类别和支持证据；
- 候选修正规则及适用范围；
- 可信度、验证次数和失效条件；
- 后续是否被新证据推翻或替代。

错误必须区分假设错误、数据问题、仿真偏差、仪器校准、实现缺陷、评价指标错误和流程错误。否则系统可能因为一次设备故障而错误地否定科学理论。

经验按照以下路径晋级：

```text
原始运行轨迹
-> 失败或异常案例
-> 候选经验
-> 独立复验后的有效经验
-> 可复用规则或 Skill
-> 多轮评估后的系统策略
```

RSI Agent 可以诊断错误并提出修正，但不能自行宣布经验有效，也不能未经评估直接改写全局规则。所有规则必须版本化、可解释、可回滚，并接受反例测试。

## 10. 如何判断一个 idea 是否有价值

CyberEinstein 不应把 idea 压缩成单一总分。至少要经过六个相互独立的判断：

1. **正确性**：证据是否真的支持这个结论？
2. **新颖性**：它是否已被论文、专利或未广泛传播的负结果覆盖？
3. **重要性**：它是否改变理论理解、技术边界或后续研究决策？
4. **稳健性**：更换数据、参数、设备或方法后是否仍然成立？
5. **投入价值**：相对于时间、成本、安全和机会成本是否值得继续？
6. **社会价值与风险**：谁会受益、谁可能受损，是否存在不可接受的滥用或不公平影响？

正确、新颖和技术上重要仍不足以自动批准一个研究项目。无法通过安全或社会影响底线的项目，不能依靠其他维度的高分抵消风险。原作者交流可以补充隐性知识，但原作者不是最终裁判。重要结论应依次经过内部反方审查、独立复现、领域专家评议、原作者沟通和适当形式的公开同行评议。公开前必须处理知识产权、保密、专利优先权和数据合规。

## 11. 核心数据资产

CyberEinstein 长期积累的不是一个论文文件夹，而是相互连接的科研记录：

- `CapabilityRegistry`：我们能做什么以及当前是否可用；
- `FieldMap`：方向历史、前沿、争议和参与者；
- `ClaimGraph`：主张、证据、反证和依赖关系；
- `ProtocolRegistry`：可执行的计算与物理实验协议；
- `RunLedger`：每次执行的环境、参数、数据和结果；
- `EvidenceLedger`：结果支持或反驳哪些 Claim；
- `ScientificExperienceBase`：失败、负结果和验证过的修正经验；
- `ReviewRecord`：内部与外部评价、质疑和回应；
- `ImpactAssessment`：受益、风险、双重用途、署名和缓解措施。

这些资产共同回答四个问题：我们知道什么、为什么相信、在哪里失败过、下一步最值得做什么。

## 12. 分阶段发展路径

### 阶段 0：科研基础建模

建立 `ResearchProgram`、`CapabilityGraph`、`ClaimGraph`、证据规则、`ImpactAssessment` 和 RSI 经验模型，完成 DeepSeek Harness 适配边界。

### 阶段 1：最小科研就绪闭环

选择一个足够窄的量子计算方向，盘点真实能力，整理 5–10 篇锚点论文，完成 Claim 拆解和分级复现，形成首个方向证据底座。

### 阶段 2：工程优化闭环

围绕一个明确指标运行可重复的 Auto Research 循环，证明系统能在严格基线、留出测试和经验回流约束下产生真实改进。

### 阶段 3：机制发现辅助

从复现异常和矛盾中提出竞争假设，自动选择判别实验，并由独立审查确认结论边界。

### 阶段 4：混合与物理实验

通过标准设备适配器接入有数字接口的实验仪器，先实现人类审批下的半自动闭环，再逐步提高自动化程度。

### 阶段 5：开放科学网络

连接原作者、合作实验室、独立复现者和公开评议渠道，使重要结果能够在受控知识产权边界下接受外部验证，也让更多普通人获得参与真实科研的入口。

## 13. 我们不提前承诺什么

- 不把生成一篇看似完整的论文视为完成科研；
- 不把一次成功运行视为结论成立；
- 不把大规模搜索中的偶然显著视为 Discovery；
- 不把 Agent 自评视为独立验证；
- 不在缺少设备、安全和授权边界时控制真实实验；
- 不声称现阶段 AI 已经能够稳定完成范式级科学发现；
- 不以“科研普惠”为名降低科学标准或淡化双重用途风险；
- 不承诺每个使用者都能获得重大发现，但承诺认真保护每个人探索科学、追求成为科学家的机会。

CyberEinstein 的进步应当用真实科研闭环来证明：更多人获得了科研能力，能力边界更清楚，复现覆盖更深入，失败不再重复，假设更可检验，实验更有信息量，结论更经得起独立审查，并且成果真正服务于人的发展和社会福祉。
