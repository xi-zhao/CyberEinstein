# Video source preservation

This additive snapshot preserves a 2026-10-03 CyberEinstein video deliverable, not the full local application repository. Sources were generated for this project from its public documentation; no private PRAgent implementation or acceptance records are included. Existing application files are unchanged.

The 21 source files have recorded source and publication SHA-256 hashes. Six files received explicitly recorded privacy edits. Original local materials remain untouched. The online preview remains the original reference and was not edited or deployed.

Only Python AST, JavaScript syntax, JSON parsing, XML narration/animation consistency and preservation-content checks were run here. The numerical example, ManimGL, TTS, model services, preview playback and full project tests were not run. See `README.txt` and `preservation.json` for the preparation requirements and historical validation boundaries.
