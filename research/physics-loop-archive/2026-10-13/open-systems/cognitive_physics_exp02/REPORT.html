2. 模型、边界与任务

三个玻色模式分别为存储 s、耗散过滤模 a 和辅助模 b。取线性耦合尺度 J=1，所有频率、相互作用和损耗用 J 归一化，时间用 J⁻¹。共同载频已在旋转坐标中消去。

B = g s + b
H₀ = B†B + a†B + B†a
L = √κ a,   κ = 2
ρ̇ = −i[H₀ + H_int, ρ] + LρL† − ½{L†L,ρ}

三模整体是明确规定的 Markovian GKLS 模型；只看 s 的约化动力学则有过滤环境的记忆。所谓“精确”均指这个已声明模型，不表示从某台真实器件的微观环境获得了全参数精确解。未纳入 s、b 的本征损耗、热激发、退相干和全部实现寄生项。

暗模及其 Fock 态为

d† = (s† − g b†)/√(1+g²)
|n_D〉 = (d†)ⁿ|0〉/√n!
H₀|n_D〉 = 0,   L|n_D〉 = 0.

这是 s 与 b 的联合编码，不是仅对裸存储 s 的无条件保护。制备、读出和允许访问辅助模的代价尚未验证。

主任务是在编码 span{|0〉,|1_D〉,|2_D〉} 上实现非线性符号操作 diag(1,1,−1)，允许已知线性相位修正。目标非谐性 U=0.1，门时间 T=π/U≈31.41593。这个任务同时检查相位与泄漏，而非只看某个态的存活概率。

数值使用总激发数截止 N≤2（维数 10），它对该任务是精确封闭的：H 保持总激发数，零温跳跃只降低激发数。高阶梯检验另用 N≤5 或 6；不是将一个未收敛的大系统简单截断。

3. 被淘汰的线性候选

在对称性保护的近暗态控制模型中，沿协议固定弱耦合，减小暗亮混合，精确慢极点与 Markov 近似的相对误差反而减小。这否定了“慢态小谱隙必然放大相对误差”的无条件规则。

另一个过滤环境的自能为（κ=2）

Σ(z) = (2z + 1 + i)/[(z+i)(z−1)−1]
Σ(0) = −1,    −2 Im Σ(x) = 2x²/|(x+i)(x−1)−1|².

裸频率位于谱零点时，二阶耗散率为零，但真实极点被能量位移移出零点，出现 Γ≈g⁶。例：g=0.1 得 Γ=9.7077954534×10⁻⁷；g=0.01 得 Γ=9.9970007998×10⁻¹³。

价值判定：不是新的机制。 Longhi 的已有 BIC 条件同时要求谱密度在本征能处为零，以及该能量满足自能方程 [R3]。本轮只重建了它的一个明确数值例子，因此没有沿着“漂亮反例”继续包装论文。

4. 第一项建设性结果：将泄漏通道分开

先限制相互作用为密度—密度形式：

H_int = U_s n_s(n_s−1)/2 + U_b n_b(n_b−1)/2 + V n_s n_b.

归一化亮组合为 e†=(g s†+b†)/√(1+g²)。在两个激发中，考虑 |2_D〉、|D e〉 和 |2_e〉，可直接得到：

U_eff = 〈2_D|H_int|2_D〉
      = (U_s + 2g²V + g⁴U_b)/(1+g²)²

C₁ = 〈D e|H_int|2_D〉
   = √2 g[U_s − (1−g²)V − g²U_b]/(1+g²)²

C₂ = 〈2_e|H_int|2_D〉
   = g²[U_s + U_b − 2V]/(1+g²)².

线性 H₀ 在暗态上为零，因此这里列出的就是非线性把暗态耦合到正交模式的通道。只有 C₁=0 不足以保证精确暗态：C₂ 仍会产生量子成对散射。

同一目标投影非线性 U 下的三个资源层次

方案 设置 通道后果
只有存储自 Kerr U_s=U(1+g²)²，U_b=V=0 C₁=√2Ug，C₂=Ug²
增加交叉 Kerr U_s=U(1−g⁴)，U_b=0，V=U(1+g²) C₁=0，C₂=−Ug²
自 Kerr 与交叉 Kerr 全匹配 U_s=U_b=V=U C₁=C₂=0

第二行是 0<g<1 的构造。第三行有 H_int=U N_sb(N_sb−1)/2，所以暗态阶梯精确保留，能量为 E_n=Un(n−1)/2。这借用了额外相互作用资源；不是在完全相同硬件资源下免费改善。

仅在此密度—密度族中、g≠0 时，保持 |2_D〉 为该非线性本征态要求 U_s=V=U_b，因为其三个裸 Fock 分量均非零且相互作用在该基中对角。这是限定族中的必要条件，不能提升成对任意控制和任意相互作用的 no-go。

衰减标度不是只靠拟合

在 g→0、固定 U 与 κ、并避开额外谱奇异性的当前参数中，精确双激发极点满足

Γ_local = c_local(U) g² + O(g⁴)
Γ_cross = c_cross(U) g⁴ + O(g⁶).

κ=2 时，定义亮区块

M₁ = [[1, 1], [1, −i]]
M₂ = [[2, √2, 0], [√2, 1−i, √2], [0, √2, −2i]]

c_local = −4U² Im[(UI−M₁)⁻¹]₀₀
c_cross = −2U² Im[(UI−M₂)⁻¹]₀₀.

在 U=0.1 下，c_local=0.0200190180672，c_cross=0.00553244222220。这些是独立亮区 resolvent 的解析领先系数，不是对曲线回归得到的系数。

80 位独立占据数矩阵构造验证了 U=0.03、0.1、0.2 与 g=0.1、0.03、0.01、0.003 的 24 个极点。g=0.003 时，精确率与上述领先项之比均在 1±1.75×10⁻⁵ 内。高精度特征方程最大残差约 1.32×10⁻⁸¹。它是高精度数值交叉检查，不是区间算术形式化证明。

5. 超出两模算例的解释：平均场平衡不等于量子阶梯闭合

对一般单个玻色模式 d†=Σ_i c_i a_i†，令 p_i=|c_i|²，Σp_i=1，考虑对称实矩阵 U_ij 定义的、保持粒子数的密度相互作用：

H_int = ½ Σ_ij U_ij a_i† a_j† a_j a_i
μ = U p,    ū = pᵀ U p
S₁ = Σ_i p_i μ_i² − ū²
S₂ = Σ_ij p_i p_j U_ij² − 2Σ_i p_i μ_i² + ū².

把 H_int|n_D〉 按“有几个粒子离开 d 模”正交分解，零、一、二正交模部分分别为

〈H_int〉 = n(n−1)ū/2
||Π₁ H_int|n_D〉||² = n(n−1)² S₁
||Π₂ H_int|n_D〉||² = n(n−1)S₂/2.

不存在三个及以上正交模的直接输出，因为相互作用是二体的。这里“正交模”不必在每个实际网络中都是耗散亮模；这些恒等式本身不是辐射率公式。

推导要点。 |n_D〉 的占据数概率是由 p 定义的多项分布。每对粒子的相互作用为 U(X_k,X_l)。令 h_ij=U_ij−μ_i−μ_j+ū，则 Σ_j p_j h_ij=0。相互作用能可分解为常数、(n−1)Σ_k(μ_Xk−ū) 和 Σ_{k<l}h_XkXl。后两项在乘积态的加权内积下正交，分别对应一、二正交模分量，直接给出以上系数。这是本轮给出的代数推导；没有把随机检验冒充证明，也未证明该恒等式在文献中首创。

平均场空间形状保持需要 μ_i 相同（在支持集上）；它消去 S₁，却可以留下 S₂>0。换言之，平均场可以保持同一个暗空间形状，而量子态仍发生双粒子离开该模式的散射。若要求整个单模量子 Fock 阶梯在这个相互作用族中精确闭合，则在 p_i p_j>0 的支持集上，需要 U_ij 全相同。

本轮用 m=2、3、4，n=2、3、4、5，三组随机复模式及三种相互作用矩阵完成 108 个独立 Fock 空间验证；最大绝对误差 8.24×10⁻¹⁴。随机种子与所有矩阵已保留。它支持公式实现正确，不代表验证了任意网络的辐射性质。

物理上值得进一步检查的命题是：平均场的非线性暗解与量子多激发保护之间，所缺的是哪个相互作用通道？ 当前构造给出了一个明确回答，但其一般意义和独立创新性仍需与既有暗态、DFS 和多体散射工作比较。

6. 压力测试触发的新构造：用成对交换替代辅助自 Kerr

最初把以下相互作用作为额外寄生项加入：

H_pair = W(s†² b² + b†² s²)/2.

结果并非所有 W 都恶化。对交叉补偿方案，当正 W 接近 Ug² 时，误差先降低。这触发了新协议 pair_exchange_pivot.json，而不是在测试后忽略这一“反常”结果。

解两粒子特征态条件，得到

U_s=U(1−g⁴),   U_b=0,   V=U,   W=Ug².

在基 (|2s〉,|sb〉,|2b〉) 上，非线性矩阵为

[[U(1−g⁴), 0, Ug²],
 [0,        U, 0],
 [Ug²,      0, 0]],

它把 [1, −√2g, g²]ᵀ 映射成 U 倍自身。

更强的任意 n 论证是母算符恒等式：

Q = b² − g²s²,    N_sb=n_s+n_b
H_int + H_pair = U/2 [N_sb(N_sb−1) − Q†Q]
Q|n_D〉=0.

因此 H|n_D〉=Un(n−1)|n_D〉/2 且 L|n_D〉=0。任意暗阶梯叠加态在声明的单损耗通道模型内保持无耗散演化，同时获得非线性相位。这一结论是代数性的，数值 n≤6 的检查只是独立实现核验。

g=0.1、0.3、0.7，n=0…6 的最大特征态残差约 1.05×10⁻¹⁵；完整 GKLS 编码过程也与理想操作一致到浮点精度。

资源与定理边界： 该构造使用可独立调节的交叉 Kerr 与成对交换。它没有辅助模自 Kerr，但不是“只加了一个原来的局部 Kerr”。它改变了 R4 的单非线性通道／非相互作用环境假设，也超出了第 4 节的密度—密度族，因此两者均未被反驳。制备、操作带宽、成对交换相位与频率匹配，以及具体电路是否同时允许这些项，均未验证。

7. 不是只看寿命：完整非线性操作的比较

采用三维编码的纠缠保真度 F_e，与非线性符号操作比较。它不是条件后选择保真度，也不是未经说明的平均门保真度。对只降低粒子数的跳跃，所有含跳跃 Kraus 算符在该编码上的对角迹为零，因此可使用无跳跃对角振幅计算 F_e；本轮另外用完整 GKLS 传播全部 9 个编码矩阵元验证了这一快捷式。

为了避免弱基线，局部 Kerr 方案可以调节存储失谐 δ，并调节 Kerr 强度，使实际极点非谐性 Re(z₂−2z₁)=0.1，而不只是投影矩阵元等于 0.1。允许修正已知线性相位。失谐在 [−0.2,0.2] 扫描 41 点后作局部有界优化；这不是全体静态或时变控制的全局最优证明。

g 仅局部 Kerr：调失谐与强度后的 1−F_e 交叉补偿：校准实际非谐性后的 1−F_e 成对交换精确构造
0.1 6.9458793×10⁻⁴ 5.7718546×10⁻⁶ 理想模型中解析为 0
0.3 6.1090317×10⁻³ 4.0987233×10⁻⁴ 理想模型中解析为 0

例如 g=0.3 的强局部基线使用 δ=−0.0726130201、U_s=0.1185250641；交叉方案使用 U_s=0.0992283829、V=0.1090421790；成对交换构造使用 U_s=0.09919、V=0.1、W=0.009。所有方案目标门时间相同。可用相互作用资源并不相同；新增资源的实现成本尚未计价。

数字反映声明模型里的操作能力，不代表现实器件能达到这些保真度，也不代表优于所有现有保护门方法。

8. 对保护条件的压力测试

全匹配密度相互作用的交叉 Kerr 出现正向偏差时，误差逐渐上升。g=0.3、10% 交叉 Kerr 偏差、重新校准投影非谐性后，F_e≈0.99990058。这里只测了明确的静态正向误差点，不是任意漂移的稳健性证书。

加入独立辅助损耗 L_b=√η b 后，原来完全保护不再成立。例如全匹配方案 g=0.3、η=10⁻³，F_e≈0.99741102。对过滤模损耗的严格暗态，不等于对所有环境噪声免疫。

成对交换构造在 g=0.3 下，交换系数 W 有 10% 正向误差时，F_e≈0.99999212；g=0.7 的相同相对误差下 F_e≈0.99894634。这里没有同时优化全部参数，也没有覆盖随机时变噪声。

这些有限测试支持“不要只报告理想的 F_e=1”，不构成硬件可用性证明。

9. 独立检查与可重跑性

完整密度矩阵方程包含跳跃回收项。直接矩阵 RHS 的 DOP853 积分与 Liouvillian 指数传播比较，最大矩阵范数差约 3.16×10⁻¹²；迹、Hermitian 性和最小特征值均有记录。编码纠缠保真度的完整传播与快捷式差小于 1.9×10⁻¹⁵。

八项科学测试全部通过，包含三个故意错误的拒绝检查：遗漏交叉 Kerr、成对交换系数误乘 2、用无跳跃非归一化态冒充无条件密度矩阵。测试是在本轮开发后添加，不是预先隐藏的盲测。

R6：多模亮暗光态 二项分布 Fock 暗态已有研究 暗态阶梯本身不是新颖性
R7：平衡交叉 Kerr 器件设计 独立非线性及寄生交换已有工程讨论 不能将假设的独立调参直接当成器件实现

本轮仍需定向核实的是：限定网络中的泄漏通道分解、部分补偿的阶数变化，以及不含辅助自 Kerr 的成对交换构造，是否已有实质等价的理论或实现。 通用暗子空间／母哈密顿量方法可以解释部分构造，所以仅仅代数优美不足以证明重要原创性。检索是定向的，不是穷尽性的；没有找到完全等价文献不代表不存在。

11. 对 loop 效果的判定

可观察到的行为变化： 文献让原先的谱零点结果降级；“存储不等于加工”将任务改为非线性操作；通道分解把单纯调参变成解析约束；更强基线显著改善原对照，避免夸大收益；压力测试中的有利意外又触发了成对交换构造。

不能据此证明： 没有等预算无认知地图对照，不能把这些结果归因于认知地图本身；没有拟合指定大师，也没有从大量论文自动抽取整个学科共识；没有独立安装后从“开放系统物理”四个字自主选题的盲测。这里是实际研究控制器与工具协同的探索，不是成熟自动科研软件的验收。

高价值门槛：本轮仍未通过。 物理假说在明确模型内获得了较强支持；价值假说只推进到“一个有机制、有操作后果的候选”，其首创性、资源可实现性和相对于现有保护方法的实质增量尚未确立。后续研究最应先处理这些会改变是否值得投入的疑点，而不是继续扫描更多参数。

本轮冻结为可复核候选和方法实验，不计作已经推进物理发展的完成成果。
