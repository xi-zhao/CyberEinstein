2. 模型与真正被优化的量

研究的是共振驱动与纯退相干的完整 Lindblad 方程：

ρ̇ = −i[Ωσₓ/2, ρ] + γ(σ_z ρ σ_z − ρ)

它保持迹与完全正性；γ>0、Ω>0 时唯一稳态为 I/2。本轮没有后选择、没有删除量子跳跃、也没有把有效非厄米哈密顿量当成完整主方程。这个目标是混合到最大混态，不是纯态复位。

令 ρ=(I+xσₓ+yσᵧ+zσ_z)/2，逐项计算得到

ẋ = −2γx     ẏ = −2γy − Ωz     ż = Ωy

于是 ṙ=A r，其中

A = [ −2γ    0     0 ]
    [   0  −2γ    −Ω ]
    [   0    Ω     0 ]

ρ-I/2 的两个特征值是 ±|r|/2，故迹距离 D=|r|/2。对全部物理初态 |r(0)|≤1 最大化，不需要随机采样初态：

D_max(t) = ½ ‖exp(At)‖₂
T_ε = inf{ t : D_max(t) ≤ ε }

最大的右奇异向量对应一个合法纯态，并实际达到这个上确界。时变情形以基本解矩阵 M(t) 代替 e^{At}，同一个公式成立。

此外

d|r|²/dt = −4γ(x²+y²) ≤ 0

这对时变正速率也成立。因此到达阈值后不会再次离开；这里不是把某个瞬时局部极小误当成永久收敛。

3. 第一项候选规则及其反例

名义 Ω=1 时，A 的非零李乌维尔特征值为 -2γ 与 -γ±√(γ²-1)。谱隙在 γ=1 最大，该点是 yz 块的二阶 EP。

但有限时间由传播子的奇异值决定，而非只由特征值实部决定。写

B = [ −2γ  −Ω ] = −γI + N
    [   Ω   0 ]
N² = (γ²−Ω²)I

于是 e^{Bt}=e^{-γt}(cI+sN)。欠阻尼区间中 k=√(Ω²-γ²)，c=cos(kt)，s=sin(kt)/k；EP 上 s=t；过阻尼区域改为 cosh 与 sinh。对这个 2×2 矩阵计算 MᵀM 的特征值得到

D_max(t) = ½ exp(−γt) [ √(1+γ²s²) + |γs| ]

x 方向衰减为 e^{-2γt}，不超过 yz 块的最大奇异值，因此上述公式覆盖所有初态。

一个不依赖数值优化器的具体构造是：令 L=ln 50，

T = √(L²+π²),     γ = L/T,     L = ln 50

此时 √(1-γ²)T=π，s=0，D_max(T)=e^{-L}/2=0.01。得到 γ≈0.7797032674、T≈5.0173228316，比 EP 的 6.4797545200 更短。这足以否定“谱隙最大必然使所规定有限精度混合最快”，不需要把这个构造证明成全局最优。

本轮还计算了 ε=0.1、0.001、0.0001；结果在 screen.json。上述解析构造不是声称对每个 ε 都最优。

4. 静态稳健性：反例迫使采样方式改变

设

γ_actual = γ_c(1+e_γ),     Ω_actual = 1+e_Ω
(e_γ, e_Ω) ∈ [−0.1, 0.1]²

每次运行中误差固定；命令值约束为 0.03≤γ_c≤2/1.1，使所有实际 γ≤2。

公平基线也优化同一误差集合下的最坏谱隙。对误差半宽 r，其最大化参数为

γ_c,gap = √[(1−r)/(1+3r)]

其来源是平衡欠阻尼角点的速率 (1-r)γ_c 与过阻尼角点 (1+r)γ_c−√((1+r)²γ_c²−(1-r)²)。本轮 r=0.1，γ_c≈0.8320502943。

最先仅用四角优化时，得到 γ_c≈0.7715810244、T≈6.5958057920。然而连续反例搜索找到 eγ=-0.1、eΩ≈-0.027206，使 D≈0.01233149194，超过 0.01。最坏误差并不总在四角。

程序把该反例加入约束，再次优化，继续找反例，共三轮：

轮次 约束情形数 γ_c 计划时间 新反例下的 D
0 4 0.7715810244 6.5958057920 0.01233149194
1 5 0.7881661000 6.8045977102 0.01000476617
2 6 0.7882028581 6.8050705528 0.010000000018

最后一行只是数值收敛，不直接充当连续误差保证。固定 γ_c 的十进制值，并把时间上调到 6.8052 后，使用 40 位区间算术细分整个误差矩形：1271 次框计算、636 个接受叶框、0 个未解决框；所有框上的 D 上界都不超过 0.01。

对反例在误差边界内部出现的位置，另有解析解释：固定最低 γ_actual 时，对 Ω 的驻点满足 tan(v)=v，其中 v=t√(Ω²−γ_actual²)。非零根 v≈4.4934094579 预测的 eΩ 与数值反例一致。此为本模型内的检查，不是一般性新定理主张。

证据：adversarial_refinement.json、interval_check.json、interval_boxes.csv、validation.json。

5. 继续探索：静态证书不能直接用于时变误差

5.1 先固定新问题，再寻找反例

上一项证书明确排除了时变误差。新动作测试的是：误差幅度仍相同，但运行期间允许变化，能否沿用相同截止时间？ 这不是宣称原有静态证书错误，而是在检验它的外推。

两个有固定计算预算的差分进化搜索都找到近似同一单次切换。优化器达到迭代上限，未返回全局收敛标记；本轮只把结果当成显式反例候选，而非最坏波形。

把其切换时刻舍入成容易重做的 τ=2.835：

  • 0≤t<τ：eγ=+0.1，eΩ=-0.1。
  • t≥τ：eγ=-0.1，eΩ=+0.1。

在原命令 γ_c=0.7882028581415226、原截止时间 T=6.8052 下，直接相乘两个传播子，得到

D_max(6.8052) = 0.012616736304685… > 0.01

60 位向外舍入区间计算的下界仍严格超过 0.01。另用完整 4×4 超算符与密度矩阵 ODE 交叉核验。

保持这个波形的绝对切换时刻不变，并在切换后持续保持第二组误差，在 t=7.1328 时仍有 D>0.01。因此任意时变误差下的最坏完成时间严格大于 7.1328。数值根约 7.133，仅作为这条波形的完成时间，不是全体时变误差的最坏时间。

5.2 不是瞬时切换的专属现象

进一步使用平滑波形

e_γ(t) = 0.1 tanh[(τ−t)/w],     e_Ω(t) = −e_γ(t)

它始终位于相同幅度盒内；最大相对误差变化率不超过 0.1/w。独立积分基本解矩阵与密度矩阵后：

平滑宽度 w 最大变化率上限 原截止时间的 D
0.05 2.0 0.01260972217
0.2 0.5 0.01250466952
0.5 0.2 0.01197043690
1.0 0.1 0.01067678961

四个例子均超标。这里只说明这些明确波形也可造成失效，不声称对所有平滑噪声或统计噪声都如此。

5.3 构造覆盖任意时变误差的充分保证

反例出现后，数值分支转去构造一个所有允许参数共享的二次型，而非继续要求模型评价反例“是否有意义”。

对 yz 向量 u，取

P = [ 1  p ] ,     |p| < 1,     V = uᵀPu
    [ p  1 ]

若所有允许的 B 都满足 BᵀP+PB≤−2αP，则 V̇≤−2αV，即使参数随时间任意可测地变化也成立。积分得到 V(t)≤e^{-2αt}V(0)，再使用 P 的最小、最大特征值 1−|p|、1+|p| 转换到欧氏范数。

本模型中该二次型提供的局部最小速率为

α = min_allowed{ γ − |γ−Ωp|/√(1−p²) }

这是对广义特征值的显式计算；程序在 200 个额外样本上与通用广义特征值求解器对照，最大误差约 1.34×10⁻¹⁵。

此处四角检查是合法的，而第 4 节只检查四角是不合法的。 原因是现在固定 P 后，矩阵不等式对 γ、Ω 是仿射的；四角成立则凸包内全部成立。有限时间传播子的最大奇异值不是参数的仿射函数，不能应用同一论证。

完整三维二次型取 diag(1,P)。x 分量满足 V̇ₓ=−4γVₓ；另行检查 2γ≥α。因此对所有初态和所有允许波形，

D_max(t) ≤ ½ √[(1+p)/(1−p)] exp(−αt)

对于原命令值，本轮找到并取安全舍入：

p = 0.7347347605884063,     α = 0.563698172

使用 60 位区间算术逐角检查 Q=−(BᵀP+PB)−2αP 的首主子式与行列式严格为正，x 分量也有正余量。在 t=8.605604 处，D 上界小于 0.01。

于是得到本模型固定命令值下的证据区间：

7.1328 < T_worst,time-varying ≤ 8.605604

上界是充分保证，不是精确最坏时间；搜索 P 时的最优也只涉及受限二次型族，不是任意控制的全局最优。

额外调整 γ_c≈0.804385626 可把这个充分上界降到 8.595535，变化仅约 0.12%。本轮不把这点小幅改进升级成重要发现。

图中静态曲线是 81×81 网格估计，不承担区间证明；静态截止时间的连续保证由独立区间检查提供。切换曲线对每个时刻均对全部初态取最坏值。绿色虚线是保守上界，不是实际最坏轨迹。

6. 核验与执行记录

初始验证包含 320 次解析式—矩阵指数对照，最大绝对差 7.87×10⁻¹⁵；48 个包含失谐的独立主方程表示检查，Bloch 与 4×4 超算符最大差 2.17×10⁻¹⁵，DOP853 与超算符最大差 9.48×10⁻¹³。含失谐的这些检查验证实现一致性，并不扩展主结论的稳健性范围。

还检查了态正性、迹、厄米性、Choi 正性及保迹性、最坏初态是否达到奇异值、迹距离单调性，以及 80 位精度下公式与矩阵指数的一致性。

三个故意注入的错误均被检出：耗散项漏掉因子 2；把真实传播子范数替换为谱隙指数；只看布居而忽略相干。

时变反例的独立密度矩阵积分与超算符差约 1.76×10⁻¹⁴。动态证书与舍入反例均使用 60 位区间算术核验，平滑波形对照误差小于 8.4×10⁻¹⁵。

区间库输出的二进制浮点展示端点最初使用普通舍入，随后改成 nextafter 向外舍入；原高精度区间判定不受影响。修正前文件保存在 revisions，日志记录了修正。区间算术是计算机辅助检查，不等于已经完成 Lean/Coq 形式化证明。

已在空目录完整重算七个数值阶段，五项关键指标与首轮数值一致。随后再次运行，复用七个断点、0 次计算启动，已有证据文件 SHA256 不变。此为同代码同环境复跑与完成断点复用检查，不是独立研究者复现，不是全新模型会话盲测，也不是全部崩溃场景验收。

以下相关工作确实限制本轮可主张的创新范围。它们不是本轮计算结果的来源，本轮也没有复现这些论文的全部结论。

8. 对“自动化科研 loop”的实际评价

真正执行的反馈包括：谱隙规则被反例否定后改用有限精度目标；四角方案超标后自动加入反例重新优化；网格不足后增加区间验证；时变误差反例触发共同二次型充分保证；查新后停止提升创新主张。

本轮由对话中的研究 Agent 进行在线选题、方法推导、文献检索和解释，工具执行计算。独立脚本中的自主部分是固定问题族内的反例搜索、约束增广、区间细分、条件分支、断点复用。run_loop.py 是本轮整理出的可重放控制器，文献判断作为冻结输入。不能把重放本案例误写成系统从零自动选题。

阶段协议在相关数值行动之前落盘，但整体工作流是在探索过程中逐步构建的，不是预先完成的外部盲测。没有学习或拟合指定大师，没有测量选题能力提升，也没有比较完整闭环与等预算裸模型的科研价值。

本轮可证明：在这个案例中，外部计算证据确实改变了下一步行动，且错误候选可以被拒绝。尚不能证明：系统能持续找到重要的新问题。

当前决策：把此案例保留为科研系统的回归样例，冻结证据；不继续在同一小模型上反复微调百分比来制造成果。下一项值得检验的研究候选应有更明确的物理后果，例如在给定硬件与噪声时间尺度下，对可用状态制备协议给出真正有增量的保证，并与现有稳健控制方法比较。这只是后续候选，不是已完成结果。
