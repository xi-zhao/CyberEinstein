# exp03：首创性与物理价值审查

日期：2026-10-13。对象：固定玻色暗模上的非线性符号操作资源下界。原 exp03 文件保持不变。

## 决策

**不计为已实现的高价值物理成果；冻结为有限条件下的理论候选，暂停模式数、参数和例图扩展。** 本次没有证明全部结果已被前作覆盖，也没有发现核心不等式的决定性反例。暂停的理由是：剩余的新颖性主张已经收窄，但尚未建立它对一个重要物理问题或已提出架构的新增后果。正确性、首创性、科学分量必须分别成立。

此次完成的是当前模型对原始论文的逐项比较、关键推导复核及全新小型实现检查，不是外部专家审稿，也不是全新模型会话盲审。文献检索属于有明确对象的定向审查；部分宽泛检索噪声很大，不能据此声称穷尽文献或证明全球首创。

## 1. 上轮遗漏的直接相关工作

Lind-Olsen 等的 *Universal Quantum Computation with Multi-Mode Schrödinger Cat States Stabilized by Non-Local Dissipation Engineering*，arXiv:2607.13975v1，首次公开记录为 2026-07-15。它在 Kerr 振子与非局域耗散阵列中提出猫态单比特及纠缠门，分析有效动力学和本征损耗。见 II.1.1、III.3、附录 B。[R4]

它不直接覆盖本轮三维 Fock 编码的任意控制下界；猫态逻辑子空间、驱动及允许资源不同。但它是“受保护存储如何支持计算”的直接前作，不能不比较就声称该问题尚待本轮打开。原 exp03 的六条参考文献没有包含它。

## 3. 核心数学检查：没有把已有结果相似当作反证

对 H0=0 的中心情形，设 |d> 为双激发暗态，psi 为未归一化无跳跃态，p=1-||psi(T)||²，eta=||psi(T)+d||。V=CVC 意味着对任意 w 属于 F=I-C，w†V=0。因此

    <w|psi(T)-d> = - integral <w|D(t)|psi(t)> dt,
    p = 2 integral <psi(t)|D(t)|psi(t)> dt.

正算符 Cauchy–Schwarz 给出

    2|<w|d>| <= ||w|| eta + sqrt(a_w p/2),
    a_w = integral <w|D(t)|w> dt.

结合允许最终线性相位修正时的 delta >= p/3 + eta²/18，对右侧作加权 Cauchy–Schwarz：

    delta >= 8 |<w|d>|² / [3(a_w + 12||w||²)].

在 F 上优化 w 即得原文矩阵逆形式。针对这些步骤，本次没有发现需要改动的系数或符号；这不是所有推广和全部极限的重新证明。

`audit_checks.py` 不导入 exp03 源码，使用新构造的随机收缩动力学作 100 个四阶段检查；最终线性相位通过驻点四次多项式求全部单位圆驻点，而非粗相位网格。关键不等式未出现违反。测试是实现与代数的辅助检查，不是定理证明，更不是价值证据。

## 4. 更关键的物理价值缺口：规模增加究竟换来何种收益？

本轮原先增加的本征噪声是同强度、独立的局域单粒子损耗：

    L_intrinsic = kappa0 sum_i D[a_i].

设 c_alpha 为任意正交规范模，其中 c_0=d。酉变换下有精确恒等式：

    sum_i D[a_i] = sum_alpha D[c_alpha].

其余规范模处于真空、信息编码在 d 的 Fock 空间时，本征损耗严格约化为

    L_intrinsic,code = kappa0 D[d].

因此，对同一 |0>,|1>,|2> 编码，把归一化模式分布到 M 个站点，并不会将本征振幅阻尼率变成 kappa0/M。|1_D> 的存活概率为 exp(-kappa0 t)，|2_D> 的无损失存活概率为 exp(-2 kappa0 t)，均不依赖 M。

这不是新发现。R4 的式 (40) 明确写出了同一规范模变换恒等式。本次用未引用旧代码的 Fock 实现对 M=1,2,3,5,8 的全部九个编码矩阵基逐项检查，最大生成元残差小于 1e-15。原始结果在 `audit_checks.json`。

**它没有推翻资源下界，也没有否认编码对指定工程化亮模损耗的保护。** 它否定的是未经证明的额外推断：“模式数增加已经改善了这类本征存储噪声，因此现在只需权衡操作代价。”现有 qutrit 模型没有建立这种增益。

多模猫态可以通过增加总激发、偏置噪声等机制具有不同价值；R2 第 III、IX 节与 R4 采用的编码不等于本轮固定低激发 qutrit。不能把那些好处自动移植过来。

同样，不允许改变暗模、不免费加入相干输运，是定理的明确条件。若实际平台可低成本重编码、输运或添加跨站点相互作用，原耗散作用量下界就不是该平台全部方案的限制。理论结果不必有即时器件演示才有价值，但至少需要证明其资源限制抓住一个重要问题，而不只是把方便绕开的路径排除在外。

## 5. 现在应怎样决定，而不是再写“待核实”

### 当前结论

- **可靠性：**中心不等式通过本次针对性重推与新实现检查；不能据此宣称完整独立审查完成。
- **新增内容：**宽泛概念、弱控制率和若干权衡均有前作；只保留有限时间、全允许控制及几何依赖这一窄主张作为候选。
- **高价值：**未达到本项目验收。未明确它改变哪个已经存在且重要的物理判断；对实际多模猫态逻辑任务的映射尚未建立。
- **投入：**暂停一般参数扫描、规模扩展和论文包装。保留证据，不删除、不继续膨胀。

### 足以重启深入研究的证据

重启不以“又找到一个更漂亮的公式”为条件。需要建立以下两种关系之一，并完成相应首创性核对：

1. 本轮界限对一项具体已有逻辑操作、分布式资源或保护架构提供了旧理论没有的必要条件，并说明它改变哪项可行性或优化判断；或
2. 核心不等式能覆盖一个本身重要、由物理资源自然限定的问题类，而其全控制结论不能由最接近前作推出。

不能仅以二者“看起来不同”或“没有检索到同一标题”为依据。若对齐后只是已有结果的直接推论，应关闭该创新分支；若物理动机不足，应换问题，而非为了保存已有工作修改项目目标。

## 6. loop 运行决策修正

少量探索仍可在价值未知时进行；但每次显著追加投入前，必须有新的贡献证据。关键行动顺序改为：

    具体重要命题 -> 最接近前作与等价性检查 -> 声明新增后果
    -> 最小研究验证 -> 再次查新增与后果 -> 决定加深或关闭。

推导和计算继续由研究执行器负责，但结果不能仅凭数值成功进入“高价值成果”状态。未解决的查新或价值疑点应产生具体审查任务，而不是被移交给用户或未来审稿人。

`decision.json` 保存本轮决策和允许重启条件。它是研究状态记录，不是已部署的自动主控器或后台任务。此次没有调用外部模型 API、用户计算机或 Codex，没有 GitHub 提交，也没有向任何作者发送未发表结果。
