# 在 Codex 等宿主中开始一个新课题

这是输入提示，不是 shell 命令。把文件放进新课题目录后，在该目录启动新会话；既有项目按 README 合并规则，不直接覆盖。

## 最简启动

复制下面文字，只需替换研究主题。资源可选，不填时先采取协议里的保守启动探测。

```text
使用项目内的 physics-discovery-loop 协议开展研究。
先读取 AGENTS.md 和 .agents/skills/physics-discovery-loop/SKILL.md。

研究主题：<填写你要尝试的物理领域或主题>
目标：自主提出并解决有实质新增与重要物理后果的问题，不预设答案。
资源：仅使用本宿主和当前目录中已授权的检索、文件与小规模计算；
不新增付费 API、GPU、权限或对外发布。先按保守探测约定执行。

先核实实际工具和当前研究状态，然后对“问题＋解法/路径＋下一行动”
做必要前审。自行决定 PROBE / ADVANCE / PARK / CLOSE；
不要每轮让我筛题。获批后实际执行，不停在调研或计划。
心智模型用于改善表征与判断，不把总结或训练当作主线。
问题、方法、结果分别通过文献核对新增性；用物理证据检查贡献。
当前可执行额度内继续；到边界时保存 research/STATE.md。
```

支持显式技能调用的 Codex CLI/IDE，可用 `$physics-discovery-loop` 起头；不依赖界面语法时，上面直接读取路径的方式是后备入口。其他宿主明确读取同一协议即可，但不能假定它自动识别 AGENTS.md 或同一路径。

## 续跑

```text
继续 physics-discovery-loop。
先读取 AGENTS.md、协议和 research/STATE.md，核对它引用的证据及未完成动作。
不要重新立项、重置预算或重复启动状态不明的计算。
从下一项待审或已批准行动继续；根据新证据决定续投或转向。
若协议缺失、来源打不开或权限不足，如实保留边界，不猜测成功。
```

## 只做前置审查

```text
按 physics-discovery-loop 审查这个候选，不开展完整研究：<候选内容>。
核对问题价值、前作覆盖、方法障碍和第一步投入。
若必须计算才能决定，仅提出或执行当前授权内的最小诊断，写明范围。
输出 PROBE / ADVANCE / PARK / CLOSE 及证据，不输出模糊分数。
```

## 宿主是否真的使用了协议

开始研究前可要求：

```text
说明你实际读取了哪些项目指令和协议文件，以及当前工具与权限。
只概括当前研究目标、前审要求和续跑入口；不要修改安全设置或执行研究。
```

这只检查入口读取。它不能证明后续持续遵守、研究质量或高价值产出。真正的机制验收需要实际动作前审、证据、决策变化与恢复测试；本包没有执行这些宿主验收。
