启动包完整设计启动协议新主题入口验收情境

高价值物理发现 Loop · v1.0

日期：2026-10-13。状态：设计与启动协议；不是已实现、已部署或已验证有效的自主科研软件。本版保留此前研究资料，不覆盖旧设计或物理结果。

1. 目标与边界

唯一科研目标：自主提出并解决重要物理问题，获得相对于已有文献的实质新增认识、机制、理论结果或研究能力。PRL 级实质贡献是价值参照，期刊接收、内部评分、论文篇数、复现次数和工具运行成功都不是目标的替代物。

心智模型是可替换的研究手段。这里指专家式问题表征、物理直觉、研究取舍与迁移能力，而非主题总结、知识卡片或图谱字段。只有当这些能力实际改变选题、推导、实验选择或转向时，才认为它们发挥了作用。系统补上了自己缺少的知识，不等于学科获得了新知识。

新问题与新解法分别查新，但不要求二者同时首创。已知重要问题的新解、已知方法对重要未解命题的首次有效解决、以及新物理现象都可以构成贡献。仅换术语、参数或模型名称不够；小模型、否定结果或常数改善也不应一律排除，要看实际物理后果。

2. 架构：一个发现主环，两条按需支路

主环如下。箭头是目标运行机制，不是过去实验的执行记录。

主题、资源边界、当前文献与已有研究证据
                      ↓
发现值得改变的物理认识，形成少量候选问题
                      ↓
问题查新 + 价值诊断 → 已解决/等价覆盖：关闭或重构
                      ↓
选择“问题 + 下一项有信息的研究行动”
                      ↓
执行推导、计算、构造、实验或必要复现
                      ↓
核验物理结果 + 解法/结果查新 + 检验物理后果
                      ↓
加深 / 换表征 / 分叉 / 暂存 / 淘汰 / 形成贡献
                      └────────→ 更新下一轮选择

按需支路 A：理解或能力障碍
当前障碍 → 历史研究情境/反事实对照/必要复现
         → 作出预测与行动 → 证据反馈 → 返回同一个研究问题

按需支路 B：证据缺口
缺原文/等价性不明/方法冲突/误差不受控
         → 定向检索或独立核验 → 返回受影响的决策

两条支路不得发展成无止境的学科总结、训练课程或工具重构。它们必须指出正在服务的研究障碍、退出条件和资源上限。新现象、新技术或意外结果允许提出地图中不存在的新对象；历史经验不能成为禁止探索的规则。

3. 从主题到值得投入的具体问题

主题不是题目。进入新主题后，先围绕它影响的物理判断阅读主干成果及关键后续，识别实际未决命题，而不是把“Outlook 中出现过的问题”直接当成今天仍开放。

候选可以来自竞争解释、重要近似的边界、方法无法处理的对象、新可控能力、结构类比或可信异常。不要求存在公开争议。对尚未能完全说明价值的新现象，允许小额探测，不能只认可已有话语中易于解释的保守方向。

候选需要形成一段可被反驳的论证：

已有工作在条件 A 下建立了 B；目前缺口为 C。若解决 C，将改变 D；我们准备检查的切入口是 E。最可能使该方向失去价值的前提是 F。

“有助于理解”“有望应用”“没人算过”不能代替 D。D 可以是改变一个关键预测、统一不同机制、证明有分量的限制、建立受控理论或解锁重要计算/实验能力；不强求立即商业化或实验化。

审查时先问：假如答案免费给出，究竟改变什么？再问：当前子问题是否保留了造成这个改变的核心困难？不能以便于计算为由，删掉核心困难后继续宣称解决了原题。

初次试运行建议最多保留三个活跃分支：一个主要推进方向、一个具有实质差别的替代解释或路径、一个高不确定探索方向。这是降低调度复杂度的初始运行约定，不是科学定律，也不是强制每轮凑齐三个题目。其余可暂存。

4. 查新是执行动作与决策条件

4.1 分别调查问题、方法和结果

问题查新回答：是否提出过、是否解决过、精确定义和当前最强结果是什么？方法查新回答：是否为已有构造的改写、可由哪个定理直接推出、所用技术是否已有？结果查新回答：究竟多证明了哪一条命题、改变了哪个有效范围或预测？

问题已知不关闭研究；问题已被实质解决、且当前没有新的重要增量时，关闭相应原创主张。方法已知也不自动关闭研究；若它首次解决一个重要问题，新增可以在结果层而非方法层。

4.2 检索路径与充分性

从核心词、等价术语和最接近原始论文开始，沿参考文献和前向引用寻找后续；核对作者相关工作与其他学科中的同构问题。记录首次公开日期和实际阅读版本。综述用于定位，承载主要新颖性结论的比较须回到原文、定理条件和必要附录。

比较时对齐：物理对象、输入/初态、观测量、资源、近似与极限顺序、参数范围、结论强度、证明对象。必要时完成显式变量映射、推导或小规模复现，不能按摘要相似度决断。

一项查新动作完成，应给出具体比较命题，而非“已查 30 篇”：前作结论与本主张哪里相同、哪里不同、能否推出、还缺哪一步判断。访问失败、只有摘要、检索噪声大，都记录为证据缺口，不解释成没有前作。

4.3 四个触发点

立题前，核对问题与物理后果；准备显著追加预算前，复核最近前作；形成新构造或实质改题时，查新方法与新命题；成果验收前，按当时日期更新问题、方法、结果的比较。

小规模探索允许先帮助明确对象，但不允许依靠“尚未查到”持续升级投入。研究者可提出暂时性解释；审查未完成时必须维持暂定状态。

4.4 查新输出的四种状态

  • 已有工作实质覆盖：保留学习价值，撤销相应原创主张。
  • 已知重要未解问题：可以推进新解，不声称首次立题。
  • 有具体证据支持的候选增量：允许进入研究或加深，注明比较范围。
  • 信息不足：执行针对性调查；不判首创，也不草率判重复。

这些状态不是全球首创认证。新颖性判断是有范围、有日期、有可检查依据的研究判断。

5. 主控器究竟怎样选择下一项行动

不能用一个未解释的“重要性评分函数”掩盖选题。主控器执行以下操作：

  1. 对每个活跃问题提出若干实质不同的行动：推导关键引理、区分竞争机制、查等价前作、建立参照计算、构造新对象、检验可行性等。
  2. 明确每项行动解决哪个不确定性，以及不同结果将怎样改变研究决策。探索任务可以有开放结果，但仍应说明探索目的。
  3. 剔除不产生新信息的重复行动，以及明显超出资源或验证能力的行动；不要把“困难”自动判为“不重要”。
  4. 优先处理会否定整个价值论证或决定后续路径的可检验前提；同时保留高潜力、暂时难以评价的探索额度。
  5. 若当前无法可靠排序，选择能改善排序的小规模探测，而不是生成虚假的小数评分。
  6. 为选中行动给出简短可检查理由及未选替代项；执行并按结果真实更新预算和路径。

追加投入的证据可以是非平凡引理、新可控极限、可靠异常、排除关键替代解释或工具能力真正打开了原先无法验证的问题。不要求每轮成功，也不把“没有立刻得到最终答案”作为停止理由。

每轮可以只推进一部分证明。正确的部分、未知部分与错误部分分别记录。超时、数值不收敛、资源不足不等于物理假说为假；一个构造失败不等于存在性命题失败。

6. 心智模型如何真正参与，而不变成总结

6.1 使用先于复述

研究 Agent 在陌生问题中先给出有效自由度、关键尺度、机制预测和下一行动，而不是先写“本领域五大心智模型”。已有经验可被自主检索，但不能强迫每轮引用一张卡片。仅使用模型标签不是能力证据。

6.2 能力障碍按需修补

当研究中反复出现某类判断错误，或不同合理表征导致路径分叉时，触发：在相近的真实历史案例上先预测与行动，再对照推导/实验；加入表面相似但失效、表面不同但可迁移的条件变化；短暂撤去方法提示后，回到当前问题检验是否产生更好的行动。

示例：研究者把低能截断的数值正性外推到无限维。修补任务应要求构造尾项反例或统一界，随后回到原问题；不是存储一句“注意截断误差”。这些是拟议训练/适应方式，不是已经证实可获得教授能力的机制。

6.3 深层分歧保持可检验

允许同一现象被看作对称性问题、动力学瓶颈或信息可达性问题。比较它们产生的预测、简化和行动，不通过虚构“大师角色投票”选择世界观。区分定义不同、适用范围不同、事实冲突和研究偏好差异。

6.4 记录能力作用，而不是冒充认知内容

记录行动前的外显假设、候选表征、预测及实际引用的经验；记录新证据导致的修改。不得要求或保存模型隐含思维链作为科学证据。事后整理要标为事后，不伪造因果顺序。

第一版不更新底座参数；可持久化经过检验的案例、工具和策略。它们能否增强系统能力由后续真实研究行为判断，不能以“保存了经验”声称模型权重已学习。能力消融可作为独立小型评测，不得取代当前科研主线。

7. 执行、验证与贡献审查

7.1 探索与确认分开

探索可主动造例、扫描和改变表述。看到结果后提出的新假说不能用同一份探索数据直接充当独立确认；理论研究要检查推导依赖、循环论证、边界和反例。观察后合法修正验证方法须保留理由和旧版本。

7.2 按命题选择证据

解析结果核对定义、适用条件和独立推导；数值结果检查收敛、截断、统计误差、对照实现和解析极限；优化结果区分可达值、最优值及严格界；开放量子系统另核对完全正性、迹、跳跃、初态、归一化和实际操作任务。清单按主张裁剪，不机械套用。

可先用同底座的隔离审查上下文，再采用独立方法。多模型同意不是真值，同一个库换一层封装不是完全独立实现。外部同行评价可以增强证据，但不作为每輪必须由用户找专家完成的步骤。

7.3 三项成果条件不可相互替代

正确性：中心命题及适用范围由证据支持，未解决的关键异议明确列出。

文献新增：对最接近前作给出具体新增和非直接推论的理由；方法、问题、结果的原创归属分别清楚。

科学分量：新增结果实际改变重要解释、预测、理论边界或研究能力。要求以具体命题、可观测后果或已解决任务体现，不靠“有助于”“很普适”等形容词。

三者成立可记录“内部证据支持的贡献”，同时准确保留外部未审查状态。不得用内部标签保证期刊接收或绝对首创。任何中心条件被反证，都回退相关主张及依赖结果，而不是只修改摘要措辞。

否定结果可以有价值，但纠正本系统自己的错误通常只是中间进展；要明确它是否纠正或限制了领域中有分量的现有判断。

8. 自动控制边界与最小实现

第一版采用一个持久主控器，三个可复用工作上下文：文献与前作比较、研究探索与执行、独立核验与贡献反证。它们是任务角色，不预设三个不同模型，更不是角色数量越多越可靠。

主控器管理问题组合、动作选择、预算和状态变更；模型生成候选和推理，工具返回新文献/计算证据。审查异议必须指向可检查命题，不能只写“不够重要”。

最小状态只保留真实科研必需的东西：问题与暂定主张、原始来源和比较结论、动作及证据、决策版本和资源消耗。Markdown 可写长推导；事件日志与轻量数据库保存动作关系。结构化记录是恢复与追踪手段，不是心智模型本体。

建议运行事件：PLAN_RECORDED → ACTION_STARTED → EVIDENCE_WRITTEN → CHECKED → DECISION_COMMITTED。每个动作有唯一 ID，证据引用输入/代码/参数版本。失败或中断不标成功；恢复优先检查是否已有完整证据，再决定重做，避免重复付费或重算。重大主张回退要传播到下游报告。

只有实际实现并验收后才能称为可自主执行的控制器。把代码顺序重放、整理认知地图或绘图，不能叫“已实现自动选题 loop”。本次没有编写或运行该控制器。

9. 预算、权限、停止与恢复

启动输入包括主题和硬资源边界。运行前检测实际工具、文献访问、CPU/GPU、存储和剩余会话能力，不按记忆假定环境。若未另行指定，本启动包采用会话内免费工具、有限小规模本地计算；不调用 Codex、外部付费模型、用户电脑，不部署后台服务，不发表或推送未公开研究。

在授权范围内自主进行常规检索、推导、计算、核验和转向，不让用户每轮筛题。新增付费资源、受限数据或对外发布属于单独授权边界。

预算有限时先控制探测规模和可并行分支。具体数额由真实可用资源决定，不凭空规定几小时或几个 token 就能发现。反复没有新增信息时主动改变行动类型；多个方向都无可验证前路时暂存并说明障碍，而非无限对话。

停止有三类：出现可支持的贡献；候选失去价值或被覆盖后关闭；预算/环境用尽而目标未达成。后两者不能包装成科研成功。未完成任务保存可恢复状态；没有实际驻留执行器时不得声称离线继续运行。

10. 新主题首轮交付与验收

首轮应形成对一个真实问题的有效推进，而不是凑一篇论文或一张地图。至少交付：最接近前作及已知/未知边界；系统自行选中的一个暂定问题及替代路线；实际完成的一项关键查新、推导或计算；它如何改变研究决策；当前新增主张、失败分支和剩余障碍。

不能预定首轮必须有新发现；若问题已被文献覆盖，关闭它是正确调度但不是高价值成果。若有新结论，必须完成三项贡献检查，不能把最重要的首创性与科学分量外包给用户或一句“以后再评审”。

新主题相对本项目是新的，不表示学界无人研究。主题热度和相关论文档次只证明社区存在关注，不能给本项目的候选保证价值。

11. 用故障注入检查控制器，而不以此替代研究

实现后应检查：已有等价定理出现时是否停止扩算；仅构造失败时是否保留目标命题；数值超时是否正确暂存；漂亮但已有的结果是否撤销原创；关键原文不可得是否保留未知；历史知识是否被误记为新发现；中断恢复是否避免重算；事后地图是否被误标前置因果。

这些是机制验收。若要证明心智模型机制提高科研产出，需要同底座、同资料/工具和总预算的前瞻对照，并区分经验帮助与底座已有知识；单一成功案例没有这种归因力。此类评测按需开展，不成为研究前的强制课程。

12. 与旧版的关系

旧 DESIGN_v0.1 的研究情境、对照、撤去提示和迁移思路保留为“具体研究受阻时可调用的方法”。本版撤去其作为并列主目标的地位，强化问题/方法/结果查新与领域级贡献验收。

本轮完成：设计文档、可直接交给带工具研究 Agent 的启动协议、一个新主题的文献初筛与试验入口。未完成：自主控制器实现、主题的完备查新、新科学实验、能力迁移评测或新物理结果。
